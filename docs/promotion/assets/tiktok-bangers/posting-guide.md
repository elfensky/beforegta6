## Manual posting sequence

1. Save the MP4 on the phone and select TikTok's add-post button, then Upload. Select the MP4 and continue.
2. Retain the existing audio and video edit. If automatic captions are offered, check GTA 6, Texas, KitKats, and the address.
3. Select the full title frame at about 2.5 seconds as the cover. Paste the complete `posting-caption.txt` into the description.
4. Set visibility to Everyone for a public post and enable comments if desired. Under Content disclosure and ads, enable disclosure and select Your brand.
5. Watch and listen to the entire preview. Use Post when the exact video, caption, and settings are accepted.

The website promotion falls within TikTok's own-brand disclosure guidance. The label is Promotional content.
The cover is the video's title card on the profile. The description supplies the accompanying text and media credits.
No website-link entitlement or existing profile configuration is assumed.
No additional post, comment, message, or profile change is part of this setup.
