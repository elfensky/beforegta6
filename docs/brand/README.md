# Favicon

The favicon uses a bold, upright `VI` monogram on the site's dark purple background (`#140a1f`).
The lettering follows the site's system sans-serif style, with a pink-to-orange gradient (`#ff4fa3` to `#ff9a4d`).
The SVG contains fixed paths and has no font dependency or external assets.

- [SVG source](../../public/favicon.svg)
- [512-pixel PNG](favicon.png)
- [Browser fallback](../../public/favicon.ico): 16, 32, and 48 pixels
- [Apple touch icon](../../public/apple-touch-icon.png): 180 pixels, opaque background

Regenerate the PNG and ICO files from the SVG with `node scripts/generate-favicons.js`.

The design reference is AI-generated with the built-in image-generation tool.
The design uses no Rockstar logo, font, or key art.

Generation brief: a centered, extra-bold geometric sans-serif `VI`; pink-to-orange lettering;
a dark purple rounded square; transparent outer corners; flat shapes; clear at 16 pixels;
no decoration, texture, shadows, or game branding.
